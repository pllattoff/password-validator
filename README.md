# Password Validator

## Passwort-Policy

Ein gültiges Passwort muss:

- mindestens 8 Zeichen enthalten
- mindestens eine Ziffer enthalten (0-9)
- mindestens einen Großbuchstaben enthalten
- mindestens einen Kleinbuchstaben enthalten
- darf nicht in der Liste häufiger oder schwacher Passwörter enthalten sein
- Das Passwort muss mindestens ein Sonderzeichen enthalten.

Erlaubte Sonderzeichen:
! @ # $ % & * ? _
